# Weekly Skill Radar

연구와 개발 작업에 실제로 도움이 되는 GitHub 저장소, 라이브러리, 에이전트 스킬을 주간 단위로 찾아 한국어로 정리하는 기준 문서입니다.

## 목표와 전달 방식

- 매주 금요일 오후 2시(KST)를 기준으로 최근 7일 동안 주목받은 기술을 살펴봅니다.
- GitHub Trending은 후보를 발견하는 출발점으로 사용합니다. 별 증가량만으로 유용성이나 품질을 판단하지 않습니다.
- 아래 관심 분야와의 직접적인 관련성, 문서와 사용 예시, 최근 유지보수, 호환성, 재현 가능성을 확인합니다.
- 관련성이 충분한 후보만 최대 5개까지 소개합니다. 적합한 후보가 적으면 개수를 채우지 않습니다.
- Slack 게시물은 한국어로 작성하고, 각 항목에 원 저장소와 근거 자료 링크를 포함합니다.
- 게시 채널은 예약 작업에서 지정한 채널을 사용합니다. 시험 채널을 정기 게시 채널로 추정하지 않습니다.

## 관심 분야

### 1. 재료과학 시뮬레이션, 구조, 그래프와 도식화

- pymatgen과 같은 결정 구조·조성·계산 결과 처리 도구
- ASE, atomate2, AiiDA, LAMMPS 및 DFT·MD·CNT 워크플로와 연결되는 라이브러리와 도구
- 구조·궤적 시각화, 과학적 그래프, 논문용 그림과 도식 제작 도구
- 계산 결과를 비교·검증하고 재현 가능한 분석으로 만드는 기능

### 2. LLM과 코딩 에이전트 활용

- Codex, Claude 및 기타 코딩 에이전트의 능력을 높이는 스킬, MCP 서버, 플러그인, 워크플로
- 이미지 이해·생성, 코딩, 데이터 분석, 연구 지원에 구체적인 개선을 주는 기능
- 각 도구가 지원하는 모델과 에이전트, 설치 방법을 구분해 설명합니다.

### 3. GPU와 HPC

- CUDA, ROCm, Triton, CuPy, JAX, PyTorch 등 GPU 가속 도구
- 시뮬레이션·수치 계산의 병렬화, 메모리 최적화, 프로파일링, 클러스터 실행 도구
- 성능 주장은 벤치마크 조건과 비교 대상을 함께 확인합니다.

### 4. 파일 정리와 분석

- 연구 코드, 계산 결과, 표, 이미지, PDF를 정리·검색·변환하는 도구
- 대용량 또는 반복 생성 데이터의 메타데이터 관리와 분석을 돕는 기능
- 로컬 파일 접근, 외부 업로드, 데이터 보존 방식이 있으면 주의사항을 표시합니다.

### 5. 문헌 검색과 PDF 분석

- 논문·특허 검색, 서지 정보 정리, PDF 파싱·주석·비교 도구
- 근거 문장과 원문 위치를 추적하고 인용·서지 정보를 검증하는 기능
- 초록이나 모델 요약만으로 논문의 결론을 단정하지 않습니다. 가능한 경우 원문과 부록의 근거를 확인합니다.

### 6. 수식 이해와 구현

- 기호 수식의 유도·검산, 단위 분석, 수치 구현을 돕는 도구와 스킬
- 수식을 코드로 옮길 때 변수 정의, 가정, 경계 조건, 차원·단위, 수렴 및 오차 검증을 지원하는 기능
- 정확도 주장에는 테스트, 기준 해법, 분석적 결과 또는 문서화된 검증 근거가 있는지 확인합니다.

## 후보 조사와 검증

1. GitHub 주간 Trending과 관련 주제·언어별 검색에서 후보를 찾습니다. 트렌딩 순위에 들지 않더라도 관심 분야에 직접 맞고 최근 주목받는 프로젝트라면 후보가 될 수 있습니다.
2. 저장소 README, 공식 문서, 릴리스·변경 이력, 라이선스, 설치 요구사항을 확인합니다.
3. 연구·정확도·성능 주장은 프로젝트 문서만으로 독립 검증된 사실처럼 쓰지 않습니다. 직접 실행하지 않은 도구는 “테스트 완료”라고 표현하지 않습니다.
4. 각 항목을 다음 기준으로 판단합니다.
   - 관심 분야 및 실제 연구 흐름과의 적합성
   - 최근 활동과 문서·예제의 충실도
   - 재현성, 정확도 근거, 유지보수 상태
   - 설치 난이도와 Codex·Claude·운영체제·GPU 호환성
   - 개인정보·코드·파일을 외부로 보내는지 여부
   - 주간 별 증가량과 관심도
5. 별 수는 인기도 신호로만 취급합니다. 근거가 부족하거나 사용 맥락이 불분명한 후보는 추천하지 않거나 제한을 명시합니다.

## Slack 요약 형식

각 후보를 짧고 구체적으로 다음 순서로 정리합니다.

- **이름과 링크** — 주간 순위·별 증가량 및 기준 기간
- **무엇을 하는가** — 저장소 설명을 한두 문장으로 요약
- **왜 볼 만한가** — 위 관심 분야의 어떤 작업에 도움이 되는지
- **호환성과 주의점** — 스킬/라이브러리/MCP/앱 구분, 지원 모델·환경, 비용·개인정보·검증상의 제한
- **근거 링크** — 저장소, 공식 문서, 릴리스, 필요한 경우 논문 등

최근 전달한 항목은 Slack 대상 채널의 이전 요약과 비교해 반복을 줄입니다. 새 릴리스나 의미 있는 변화가 있으면 다시 소개할 수 있으며, 재등장 이유를 밝힙니다.
