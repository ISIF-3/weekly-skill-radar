# Weekly Skill Radar

GitHub에서 주목받는 저장소, 라이브러리, 에이전트 스킬을 찾아 핵심 내용을 한국어로 소개하는 기준 문서입니다. 개인 연구와의 직접적인 연관성을 억지로 끌어오지 않고, 각 프로젝트가 무엇이며 어떤 기능과 특징이 있는지를 설명하는 데 중점을 둡니다.

## 운영 기준

- 매주 금요일 오후 2시(KST)를 기준으로 최근 7일 동안 주목받은 프로젝트를 살펴봅니다.
- GitHub Trending과 주제별 검색을 후보 발견에 사용합니다. 트렌딩에 없더라도 아래 관심 분야에서 새롭거나 설명할 가치가 있는 프로젝트는 후보가 될 수 있습니다.
- 별 증가량은 주목도를 보여주는 참고 정보이며, 품질·정확성·유용성의 증거로 취급하지 않습니다.
- 가능한 경우 같은 출처와 같은 기간의 순위·별 증가량을 함께 비교합니다. 자료의 집계 시점이나 기간이 다르면 수치를 한 순위처럼 비교하지 말고 차이를 밝힙니다.
- 주당 핵심 후보 3개 안팎을 소개합니다. 소개할 만한 후보가 적으면 개수를 채우지 않습니다.
- 결과는 한국어로 작성하고 원 저장소와 주요 근거 자료에 링크합니다.
- 정기 Slack 게시에는 예약 작업에서 지정한 채널을 사용합니다. 시험 채널을 정기 게시 채널로 추정하지 않습니다.

## 관심 분야

다음 분야를 넓게 살펴봅니다. 모든 후보가 개인 연구에 직접 연결되어야 하는 것은 아닙니다.

1. **재료과학·과학 계산:** pymatgen, ASE와 같은 구조·계산 도구, 시뮬레이션 워크플로, 과학 그래프·구조 시각화·도식화
2. **LLM·코딩 에이전트:** Codex·Claude 등에서 이미지, 코딩, 분석, 문서 작업을 돕는 스킬·MCP·플러그인·워크플로
3. **GPU·HPC:** GPU 가속, 병렬 계산, 메모리 최적화, 프로파일링, 클러스터 활용 도구
4. **파일·데이터 작업:** 파일 정리, 검색, 변환, 추출, 대량 데이터 분석 도구
5. **문헌·PDF:** 논문 검색, PDF 읽기·요약·비교, 서지·인용 관리 및 근거 추적 도구
6. **수식·구현:** 수식 이해와 유도, 기호·수치 계산, 수식을 코드로 구현하고 검산하는 도구

## 후보 확인 방법

- 저장소 README와 공식 문서를 우선 확인해 프로젝트의 목적, 핵심 기능, 사용 방법을 파악합니다.
- 항목을 **라이브러리, 앱, CLI, 에이전트 스킬, MCP 서버, 플러그인** 등 실제 유형에 맞게 부릅니다. 패키지나 라이브러리를 에이전트 스킬이라고 표현하지 않습니다.
- 지원 모델·환경, 설치 조건, 라이선스와 외부 서비스 의존성이 확인되면 간단히 설명합니다.
- 정확도·성능·보안에 관한 프로젝트의 주장은 출처를 붙이고, 독립적으로 검증된 사실처럼 쓰지 않습니다. 직접 실행하지 않은 도구는 테스트했다고 표현하지 않습니다.
- 개인 연구와의 직접적인 관련성이 약하면 그 연결을 만들지 않습니다. 활용 예시는 저장소의 기능에서 자연스럽게 도출될 때만 짧게 덧붙입니다.
- 최근 커밋이나 활동 내역은 기본 소개 항목에서 제외합니다. 유지보수 상태나 최근 변경이 판단에 꼭 필요할 때만 주의점으로 언급합니다.
- 사용자의 코드·파일·연구 데이터가 외부로 전달될 수 있는 도구는 그 사실이 문서에 명시된 경우 주의점에 표시합니다.

## Slack 소개 형식

각 항목은 아래 내용을 중심으로 짧고 읽기 쉽게 씁니다.

- **이름과 저장소 링크**, 분류
- **한 줄 소개:** 무엇을 해결하거나 제공하는 프로젝트인지
- **주요 기능·특징:** 눈에 띄는 기능이나 다른 점
- **이번 주 주목 이유:** 주간 순위·별 증가량 등 확인 가능한 근거와 집계 기간
- **지원 환경·주의점:** Codex/Claude 호환성, 설치 조건, 비용·데이터 처리 등 독자에게 중요한 정보
- **출처 링크:** README와 필요한 공식 문서

마지막에 개인 연구와의 적합성을 점수화하거나 단정하지 않습니다. 후보를 다시 소개할 때에는 중복 여부를 확인하고, 새로 주목할 변화나 계속 살펴볼 이유가 있을 때만 간단히 설명합니다.
